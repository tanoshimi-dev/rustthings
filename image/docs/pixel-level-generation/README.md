# Pixel-level generation

## Purpose

This sample focuses on building images directly from code, one pixel at a time.

## Project

- `E:\dev\vs_code\products\learning\rustthings\image\prj\07-pixel-level-generation`

## What the program does

- creates a gradient image
- creates a checkerboard pattern
- creates a simple heatmap

## Key Rust APIs

- `ImageBuffer::from_fn`
- direct RGB color generation

## Run

```powershell
Set-Location E:\dev\vs_code\products\learning\rustthings\image\prj\07-pixel-level-generation
cargo run
```

## Output

Generated images are written to the project's `output\` folder.
